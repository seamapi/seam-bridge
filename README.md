# Seam Bridge

Seam Bridge is a lightweight application that brings on-premises access systems online. Run Seam Bridge on a computer within the same local network as your on-premises access system, and it provides a secure tunnel between Seam Cloud and the local system. Seam Bridge handles encryption and authentication. It's very secure and does not require you to expose ports to the public internet.
With Seam Bridge, enjoy the stability of an on-premises access system, while also being able to connect it to the cloud.

For more information, see the [Seam Bridge docs](https://docs.seam.co/latest/capability-guides/seam-bridge).
